## 验收记录最低字段

每次真实验证至少记录：
- YuanQi commit SHA / package version；
- DSH 版本和 Profile；
- 操作系统、设备和 Node.js 版本；
- 测试命令或可复现步骤；
- 预期结果、实际结果；
- 日志/报告位置（脱敏）；
- 失败分类和是否阻断发布。
