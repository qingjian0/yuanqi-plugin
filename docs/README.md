## 文档分类

- `adr/`：架构决策记录，保存背景、方案、决策状态和影响。
- `research/`：技术研究、算法依据、数据来源、精度边界与验证结果。
- `EXECUTION-PLAN.md`：阶段执行计划（若存在，以仓库文件为准）。
- `IMPLEMENTATION-LOG.md`：实施过程、变更记录、测试结果和未完成事项（若存在，以仓库文件为准）。

## 文档维护约定

1. 以简体中文作为默认维护语言。
2. 明确区分用户决策、仓库事实、研究中、规划中、待确认和实现冲突。
3. 当前实现以源码、测试和真实宿主证据为准；历史对话用于恢复用户意图。
4. 天文、历法和时间尺度内容必须注明算法/数据来源、适用范围与精度边界。
5. 涉及出生资料、位置、记忆和经验时，明确数据来源、用户确认边界及持久化范围。
6. 设计变更同步更新相关 ADR、决策登记册和导航。
7. 不得将未运行的测试、未安装的依赖或未完成的宿主验收写成已通过。
8. 概念架构图不等同于当前源码调用图；研究目标不等同于已实现功能。
9. 不将对话摘要冒充为完整逐条历史聊天审计。
