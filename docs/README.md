# 元炁项目文档

本目录存放元炁（YuanQi）设计决策、实施记录和技术研究资料。

**默认语言：简体中文（zh-CN）。** 新增或实质性更新的文档应优先使用简体中文。代码、协议、标准、API、库名和专有术语保留原文，并在首次出现时补充中文解释。英文原始资料可保留，但应提供中文摘要或中文索引。

## 文档分类

- `adr/`：架构决策记录（ADR），记录为什么作出某项设计选择及其约束。
- `research/`：技术研究、算法依据、数据来源、精度边界与验证结果。
- `EXECUTION-PLAN.md`：阶段计划、任务拆分和验收条件。
- `IMPLEMENTATION-LOG.md`：实施过程、变更记录、测试结果和未完成事项。

## 文档维护约定

1. 以简体中文作为默认维护语言；不要只更新英文文档而遗漏中文说明。
2. 每项结论区分“已实现”“本地测试通过”“宿主验证通过”“仍待验证”。
3. 天文、历法和时间尺度内容必须注明算法/数据来源、适用范围、精度或不确定度；不得把近似模型写成高精度事实。
4. 涉及用户出生资料、位置、记忆和经验时，明确数据来源、用户确认边界及持久化范围。
5. 设计变更同步更新相关 ADR、研究文档和本页导航。
6. 不得将未运行的测试、未安装的依赖或未完成的宿主验收写成已通过。
