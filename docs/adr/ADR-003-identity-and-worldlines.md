# ADR-003：身份连续性与世界线

- 状态：Accepted principles / Open details
- 决策主题：一个身份，多条隔离世界线。

## 背景
长期个体连续性需要支持分支探索，同时防止不同分支经历和记忆意外串线。

## 已确认原则
- 身份连续性与世界线状态分开建模。
- 多条世界线必须逻辑隔离。
- 分支、切换、恢复和去重必须保持边界。
- worldline_id 仅是逻辑隔离键，不是身份认证或授权凭证。
- 跨世界线转移只能针对明确授权且经过证据核验的数据。

## 未决细节
双主体、多中心自我模型的身份语义；世界线合并/分支策略；授权证据迁移的粒度、审计、撤销、冲突解决和回滚。

## 当前实现边界
alpha.9 STATUS 记录按 DSH Session 隔离、分支、切换、事件恢复与去重。不能据此宣称跨世界线授权迁移已经完整实现。
