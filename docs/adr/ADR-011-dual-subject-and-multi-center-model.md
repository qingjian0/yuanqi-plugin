# ADR-011：双主体与多中心自我模型

- 状态：Open
- 决策主题：历史设计中的双主体、多中心与单一身份连续性如何统一。

## 背景
历史项目讨论提出双主体、多中心自我模型、一个身份与多条隔离世界线。当前 ARCHITECTURE 使用单一动态 Self-model 概念图，尚未完整说明主体与中心的语义边界。

## 待回答问题
1. “双主体”指两个主体、主体与观察者，还是两个协作的认知过程？
2. “多中心”是多个功能中心、观点中心还是具备独立状态的子主体？
3. 一个身份如何与多个中心保持连续性？
4. 哪些记忆/状态共享，哪些按世界线隔离？
5. 冲突时由什么规则协调，如何避免一个中心越权修改另一个中心？
6. 跨世界线迁移是否需要主体级授权？

## 暂定原则
在用户确认语义前，不把双主体/多中心作为已冻结数据模型，也不擅自新增实现。先完成概念定义、状态边界、证据规则和可测试不变量。
