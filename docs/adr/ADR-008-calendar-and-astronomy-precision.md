# ADR-008：历法与天文精度边界

- 状态：Accepted principles
- 决策主题：时间计算必须注明算法、数据来源和精度边界。

## 当前仓库事实
入口导出民用时间、太阳时间、四柱、节气太阳黄经求根、Meeus 太阳星历、IERS EOP、TAI-UTC、Delta-T 等模块。

## 决策
- 区分民用时间、时区、UTC/TAI/TT 等时间尺度。
- 区分算法近似、外部数据、计算结果和用户原始输入。
- Meeus 低精度太阳模型是实用近似，不是边界级高精度星历。
- 接近节气、日界或时辰边界时必须独立核验。
- 夏令时重叠时间需明确选择偏移。
- 不得仅凭函数导出或单元测试存在就宣称历法结果完全正确。

## 验收
建立独立参考数据集、边界样本、误差统计和可复现报告。
