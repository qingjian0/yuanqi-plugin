# ADR-010：动态自我模型作为长期架构核心

- 状态：Accepted research direction
- 决策主题：自我模型是动态领域模型，不是固定人格描述。

## 决策
自我模型应能够被经历更新、被记忆证据支持、被认知检查和反思，并可解释地参与目标评估与行为选择。它需要保留来源、时间、不确定性和修订历史。

## 不能等同
自我描述文本不等于动态自我模型；动态自我模型不等于主观意识；元认知流程不证明现象意识；目标驱动行为不证明独立意志。

## 当前边界
当前 ARCHITECTURE/README 将其定义为长期研究架构核心。完整自我模型模块尚未被 STATUS 标记为 alpha.9 已实现。

## 后续设计
先定义领域对象、证据引用、候选更新、提交、冲突、反思、版本和世界线边界，再决定数据库/工具接口。避免先增加无明确语义的 self 字段或 self_awareness 工具。
