# ADR-002：先天基线与后天经历

- 状态：Accepted
- 决策主题：先天为本，后天为用。

## 背景
元炁需要明确区分初始化条件与运行过程中持续形成的状态，避免普通经历覆盖初始资料。

## 决策
先天基线是初始化时建立且有明确来源的参数；后天经历是运行中形成的事件、交互、行为和结果。普通经历不得静默覆盖先天基线。修改基线必须有明确操作、来源和记录。

## 用户资料规则
用户出生资料只能由用户主动提供并明确确认。不得通过 IP、设备定位、年龄推算或模型推断补全出生事实。原始资料、计算结果和推演结果必须分离。

## 影响
领域模型、存储、审计和上下文投影必须保留来源与状态。该建模原则不意味着出生资料决定人格或命运。
