# 元炁架构决策记录（ADR）

ADR 用于保存决策背景、候选方案、决策状态、影响和验证要求。状态必须诚实区分：
- **Accepted**：有明确用户确认或当前仓库明确采用。
- **Proposed**：建议方案，尚未确认。
- **Open**：存在待确认问题。
- **Conflict**：历史用户决策与当前实现/文档不一致。
