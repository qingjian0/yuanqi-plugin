# ADR-012：平台支持与验收

- 状态：Open
- 决策主题：平台目标与真实宿主验收分离。

## 历史目标
历史讨论涉及 Android、桌面 Linux 和 Windows。当前项目以 DSH 插件为交付形态。

## 当前仓库验证边界
alpha.9 状态文档记录真实 Android DSH 宿主安装运行、真实模型会话端到端和 Android/iOS 端到端尚未完成。peer dependency 版本范围不等于全范围兼容验证。

## 决策要求
每个平台建立独立兼容矩阵，记录 DSH 版本、OS/设备、Node.js 运行环境、安装方式、工具调用、持久化、会话隔离、升级/卸载和失败日志。没有真实证据的平台标记为目标平台或待验收，不标记为已支持。
