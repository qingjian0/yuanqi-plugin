## 历史对话阶段

### 早期：XuanShu / BirthSeed 探索
- 曾使用 XuanShu 作为早期项目名称，讨论出生资料、BirthSeed/BSN 编码和初始化模型。
- 早期原型曾涉及 P7 校验、出生码编解码、数据验证与协议结构。
- 早期测试数量（例如 18 项通过）仅属于当时原型记录，不代表当前 alpha.9 测试结果。
- 早期设计曾涉及 Python/JavaScript 兼容、历法、记忆主体和 Worldline 等问题；后续技术路线以当前仓库为准。

### 2026-10-25：正式更名与核心原则
- 历史记录显示项目由 XuanShu 更名为元炁 YuanQi。
- 核心理念确定为“先天为本，后天为用”。
- 研究方向扩展至记忆、经历、认知、情感、性格、自我模型、目标、自主性和个体演化。
- BirthProfile 初始化规则和元炁自身唤醒时间开始被明确区分。

### 2026-10-26：DSH 插件路线
- 明确以官方 DeepSeek Harness 为宿主，元炁是插件而非独立 Agent Runtime。
- 讨论插件生命周期、工具、存储、Session、出生资料及世界线。
- 历史路线包括 Android 使用场景，但平台目标不等于真实设备验收。

### 2026-11-03：正式仓库基线
- 历史记录确认正式仓库为 `qingjian0/yuanqi-plugin`。
- 要求后续以 GitHub 实际源码、提交、分支和测试为准，避免把讨论中的设计当成实现。
- 许可证后来确定为 GPL-3.0-only；当前仓库元数据已核对一致。
