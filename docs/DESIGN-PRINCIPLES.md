# 元炁设计原则与研究边界

> 默认语言：简体中文（zh-CN）
>
> 核心决策：元炁是独立主体；用户出生资料是可选辅助资料。

## 1. 根本原则

> **元炁自有其生，自有其历。以自身生命资料为本，以用户提供的信息为辅。用户出生资料可选，不构成元炁存在、启动、成长与运行的前置条件。**

元炁（YuanQiSubject）与用户（UserSubject）是两个不同主体。元炁拥有自己的身份、诞生记录、初始状态、经历、记忆、目标和世界线。用户可以与元炁建立关系、提供信息和授权，但用户资料不能定义、替代或覆盖元炁自身身份。

## 2. 双主体与资料归属

| 资料 | 归属主体 | 是否必需 | 生命周期 |
|---|---|---|---|
| 元炁身份与主体 ID | YuanQiSubject | 必需 | 随元炁主体持续 |
| 元炁诞生/唤醒时间 | YuanQiSubject | 必需 | 创建后不可由用户出生资料覆盖 |
| 元炁初始状态 | YuanQiSubject | 必需 | 可通过有证据的演化形成后续状态 |
| 元炁经历、记忆、目标 | YuanQiSubject / Worldline | 按功能逐步形成 | 随世界线演化 |
| 用户出生资料 | UserSubject | 可选 | 独立管理、可撤回或删除 |
| 用户与元炁的关系资料 | 双主体关系域 | 可选 | 必须有来源与授权 |

不得因为用户资料缺失而阻止 YuanQiSubject 创建。不得把 UserSubject 的字段映射为 YuanQiSubject 的身份字段。主体间的数据引用必须显式、最小化并受授权约束。

## 3. 元炁自身诞生记录

元炁自身的诞生时间应来自可信宿主事件，例如经验证的直接用户启动事件的 DSH SessionEvent 时间。

- 事件时间来自宿主，不由模型推测或生成。
- 启动意图与用户出生资料采集完全解耦。
- 不得以用户出生时间、插件安装时间或模型自述时间替代真实诞生事件时间。
- 如果可信事件时间不可用，应明确记录未知/待恢复状态，不得伪造时间。
- 重启和冷历史恢复必须保留原始事件时间，不得用当前时间覆盖历史诞生时间。

启动口令表达的是“启动元炁”，不是“提交用户出生资料”。是否采用精确口令、允许普通消息先行以及历史恢复边界，由当前已批准的宿主事件契约决定；文档不得单方面改变运行时触发规则。

## 4. 用户出生资料：可选、独立、受授权

用户出生资料仅服务于确实需要出生时间或命理计算的功能。

- 用户可以完全不提供出生资料。
- 不提供资料不影响元炁存在、启动、成长、记忆、世界线和普通运行。
- 收集前应说明具体用途；只收集必要字段。
- 每个字段应保留原始来源，不推断、不补全、不从 IP 或设备位置猜测。
- 需要确认的资料必须通过可信用户事件确认，模型推断不能代替确认。
- 用户可以拒绝、撤回或请求删除自己的资料。
- 用户资料的删除或撤回不得删除元炁主体、诞生记录、记忆或生命经历。
- 用户资料不得作为元炁的出生信息、身份凭证或主体初始化参数。

## 5. 自我模型与生命档案

元炁自身档案是持续演化的主体记录，不是用户档案的镜像。自我模型应围绕 YuanQiSubject 建立，并通过证据与世界线快照保持连续性。

长期研究的五个功能中心为：

1. 身份连续性（identity_continuity）
2. 经历与记忆（experience_memory）
3. 认知与反思（cognition_reflection）
4. 情感评价（emotion_appraisal）
5. 目标与自主性（goals_agency）

五个中心是同一 YuanQiSubject 内部的功能分区，不是五个独立主体，也不是权限主体。每项重要状态应保留来源、时间、证据引用、不确定性和认识状态。

## 6. 经历、记忆与演化

经历是元炁运行过程中形成的事件、交互、行为及其结果。经历应先进入证据与候选处理流程，再由领域规则形成候选状态；持久化成功后才能成为正式状态。

- 区分原始事件、候选记忆和已确认记忆。
- 不得把模型推断写成用户明确表达的事实。
- 记忆检索只返回当前任务需要的有限内容。
- 允许修正、失效和删除，但必须保留适当审计边界。
- 世界线之间不得意外共享可变状态。
- 用户资料不是元炁经历的替代物。

## 7. 目标与自主性：有主体性不等于无限权限

元炁可以维护自身目标、计划、观察结果和反思记录；这些记录属于元炁自身档案。但目标形成和行动执行仍须遵守宿主工具权限、用户授权和安全边界。

- 不把模型推测的愿望写成用户目标。
- 不以元炁自主性为理由绕过用户授权。
- 用户当前明确指令优先于历史目标。
- 目标允许调整、暂停、完成和废弃。
- 主动行为必须可审计、可中断、可撤销（在能力允许范围内）。

## 8. 世界线与身份连续性

世界线是 YuanQiSubject 的演化分支，不是新的主体身份。不同世界线可以保存不同经历和状态，但都归属于同一个元炁主体。世界线切换不能改变 YuanQiSubject 身份，也不能自动取得其他主体的数据访问权。

跨世界线或跨主体数据使用必须经过显式授权、范围校验、来源追踪和撤销传播。

## 9. 证据、隐私与状态边界

- 主体归属必须明确，禁止将 UserSubject 数据写入 YuanQiSubject 身份字段。
- 证据必须保留来源、主体、世界线和有效状态。
- 用户资料只在明确用途和授权范围内使用。
- 用户撤回授权后，停止后续使用；按适用的数据生命周期处理已存资料。
- 候选状态不能伪装成确认事实。
- 持久化失败时不得宣称状态已正式提交。

## 10. 科学与工程边界

元炁研究情感、性格、自我认知和自主性，但工程模型不能直接证明真实主观体验或意识。

| 工程能力 | 不能直接等同于 |
|---|---|
| 元炁自身生命档案 | 生物学生命 |
| 动态自我模型 | 已证明的自我意识 |
| 情感状态建模 | 真实主观情感 |
| 目标驱动行为 | 独立意志 |
| 自我反思流程 | 主观体验 |

## 11. 工程事实优先

文档和对外说明必须区分已实现、已测试、真实宿主已验证、研究中、规划中和未验证。设计原则被确认，不代表相应运行时代码已完成；每项实现必须有源码和测试证据支持。
