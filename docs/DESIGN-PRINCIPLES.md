# 元炁设计原则与研究边界

> 对应版本：`1.1.0-alpha.9`  
> 默认语言：简体中文（zh-CN）

## 1. 核心原则

> **先天为本，后天为用；先天的是本色，后天的是经历。**

这是元炁的软件设计原则，不代表出生资料能够决定人格，也不代表相关人格、心理或意识模型已经获得科学验证。

元炁希望构建能够持续积累经历、保留记忆证据、调整内部状态、形成个体差异并维持身份连续性的 AI 生命上下文系统。

## 2. 先天基线：明确、可追溯、不可静默覆盖

先天基线是初始化时建立的基础参数。

- 起始参数必须有明确来源。
- 元炁自身出生时间必须来自可信 DSH Host 唤醒事件。
- 元炁自身出生地点只接受与唤醒时间匹配的宿主授权定位；不可用时保持未知。
- 用户出生资料不属于 YuanQiSubject，不得用于初始化或补全元炁 BirthProfile。
- 不得通过 IP、服务器所在地、年龄推算或模型推断补全元炁出生事实。
- 原始资料、计算结果和推演结果必须区分。
- 普通经历不能静默覆盖先天基线。
- 基线修订必须有明确操作、来源和记录。

先天基线是领域模型的初始条件，不是对人格或命运的确定性判定。

## 3. 后天经历：持续输入、证据优先

经历是运行过程中形成的事件、交互、行为及其结果。

每项重要经历应尽可能保留：
- 来源和原始证据；
- 发生时间与记录时间；
- 事件内容和参与对象；
- 行为及其结果；
- 支持证据与反证；
- 当前处理状态。

经历经过领域计算形成候选状态。只有在满足确认和持久化要求后，才能成为正式状态。

## 4. 记忆：不是全部历史

记忆用于支持当前认知和行为，不是全部对话历史的简单复制。

- 区分候选记忆和已确认记忆。
- 候选记忆保留用户原文证据。
- 需要用户明确确认后才能升级为已确认记忆。
- 检索返回与查询相关的有限结果。
- 允许修正、失效和删除。
- 不得把模型推断写成用户明确表达的事实。

## 5. 自我模型：动态中枢，而非人格字段

自我模型（Self-model）是元炁长期架构的核心研究对象。

它应当：
- 被经历更新；
- 被记忆支持；
- 被认知检查和反思；
- 保留来源、时间和不确定性；
- 对目标评估和行为选择产生可解释的影响；
- 在新证据出现时允许修正；
- 与世界线和 Session 生命周期保持一致。

自我模型不能退化为固定人格简介、单一数据库字段或提示词中的自我描述。

必须区分文本层面的自我描述、工程意义上的动态自我模型、元认知能力，以及尚待研究的主体性和意识问题。

## 6. 情感：研究状态变化与反馈机制

情感研究不应只使用静态情绪标签。

需要研究：
- 状态如何形成；
- 哪些经历触发变化；
- 记忆如何影响情感评价；
- 情感如何影响认知与目标；
- 情感状态如何参与行为调节；
- 新经历如何反过来改变情感状态。

工程系统能够实现情感状态建模，不等于证明系统拥有真实主观感受。

## 7. 性格：由长期模式形成，不由标签预设

性格方向关注长期行为、经历、记忆、价值倾向和自我评价之间的关系。

- 不以固定人格模板作为核心。
- 区分短期状态和相对稳定倾向。
- 记录样本量、时间范围和证据质量。
- 允许矛盾、变化和不确定性。
- 不把有限行为样本解释为确定人格事实。

## 8. 目标与自主性：内部驱动不等于无限权限

目标系统应区分目标、计划、实际行为和观察结果。

- 活跃目标可以影响经历相关性和决策排序。
- 目标应允许调整、暂停、完成和废弃。
- 目标冲突需要显式处理。
- 模型推测的愿望不能直接写成用户目标。
- 用户当前明确指令优先于历史目标。
- 主动行为必须受工具权限、用户授权和安全边界约束。

自主性研究不能成为绕过用户授权的理由。

## 9. 行为倾向：暂定估计

行为倾向需要考虑样本量、时间跨度、证据来源和反证。

置信分数若使用工程启发式计算，必须明确标注其含义，不得冒充心理学概率或科学测量结果。系统不能承诺确定性行为预测。

## 10. 世界线与连续性

世界线用于隔离不同演化分支中的状态。

- 世界线是逻辑隔离机制，不是身份认证。
- Agent/Session 路由优先使用可信宿主上下文。
- 模型不能通过任意填写标识符扩大数据访问范围。
- 分支、切换、恢复和去重应保持数据边界。
- 不同世界线之间不得意外串入记忆、证据缓存或上下文。

## 11. 上下文：数据不是指令

注入模型的历史信息应作为数据使用，不应覆盖用户当前请求。

- 只注入当前 Session 对应的有限上下文。
- 不重复注入工具续步。
- 不默认注入完整聊天历史。
- 明确区分事实、候选信息、推断和不确定性。
- 当前用户明确指令优先于历史记忆、经验和目标。
- 上下文生成失败不得阻断宿主普通对话。

## 12. 可验证性与科学边界

元炁应将研究假设转化为明确模型、可观测指标、可重复实验和可证伪条件。

必须区分：

| 工程概念 | 不能直接等同于 |
|---|---|
| 情感状态建模 | 真实主观情感 |
| 动态自我模型 | 真正的自我意识 |
| 自我反思流程 | 主观体验 |
| 目标驱动行为 | 独立意志 |
| 个体状态演化 | 大模型权重进化 |
| 可观察认知行为 | 现象意识 |

任何意识相关结论都需要独立的理论论证和实验支持。对话表现本身不能证明意识产生。

## 13. 工程事实优先

文档和对外说明必须区分：
- 已实现：当前源码存在相应实现；
- 已测试：对应自动化测试实际运行通过；
- 宿主已验证：目标 DSH 环境中完成真实验收；
- 研究中：有明确设计但实现或验证尚不完整；
- 规划中：已确定方向但尚未实现；
- 未验证：有实现或声明但缺少目标环境证据。

不得将旧版本测试数量、旧版架构或研究原型结果直接写成当前版本能力。
